# GePeGe 0.2b

- Publicación voluntaria de la clave pública recién generada en keys.openpgp.org, previa confirmación de la huella. El servidor envía un correo de verificación para permitir búsquedas por dirección.
- Compilación para Windows x86-64, con instalación independiente de Gpg4win y pruebas automatizadas.
- Continúa disponible el AppImage para Linux x86-64. Ambas versiones requieren GnuPG instalado.
